# Triage labels

本仓库沿用五个默认角色。技能提到某个分诊角色时，使用下表对应的 GitHub 标签。

| 角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者分诊。 |
| `needs-info` | `needs-info` | 等待补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 需求充分明确，可由 agent 领取。 |
| `ready-for-human` | `ready-for-human` | 需要人工实现。 |
| `wontfix` | `wontfix` | 决定不处理。 |
